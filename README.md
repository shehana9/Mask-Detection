# Face Mask Detection

A computer vision project that uses YOLOv5 to detect whether a person is wearing a face mask or not.

## Project Description

This project uses the YOLOv5 object detection model to detect face masks in images.

The model was trained using a face mask dataset from Roboflow and trained on Kaggle.

## Technologies Used

- Python
- YOLOv5
- OpenCV
- Kaggle
- Roboflow

## Model Training

The YOLOv5s model was trained for 99 epochs using the face mask dataset.

Training was performed on Kaggle.

## Dataset

The dataset was obtained from Roboflow and used through Kaggle.

## How It Works

1. The face mask dataset is prepared.
2. YOLOv5 is downloaded and its requirements are installed.
3. The YOLOv5s model is trained on the dataset.
4. The trained model can then be used to detect face masks.
